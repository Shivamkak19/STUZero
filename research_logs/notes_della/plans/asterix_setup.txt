SESSION SUMMARY

  Goal                                                                   
   
  Set up offline dynamics training experiments for Asterix (previously   
  only had Pong) to test if spatial STU rollout stability generalizes
  across Atari games.

  What was done

  1. Data Collection for Asterix
  - Created SLURM script (slurm/collect_asterix.sh, later moved to
  collect_asterix.sh) to collect dynamics dataset from the Asterix
  benchmark checkpoint (models/model_asterix_110000.p) using
  collect_data.py
  - Dataset was successfully collected: 50 episodes, 184,876 transitions,
   saved to dynamics_dataset_asterix/

  2. HuggingFace Dataset Restructuring
  - Reorganized HF repo from Shivamkak/STUZero-Pong-Dynamics to
  Shivamkak/STUZero-Atari-Dynamics
  - Structure: pong_100K/ and asterix_110K/ subfolders, each containing
  episode files, metadata, and the benchmark model checkpoint
  - Wrote root-level dynamics_dataset_readme.md describing the multi-game
   dataset, collection procedure, and data fields
  - Uploaded model files (pong_model_100000.p, asterix_model_110000.p)
  into their respective HF subfolders

  3. train_dynamics_offline.py Updates
  - Added --game argument (pong | asterix) that auto-resolves data_dir,
  checkpoint, and action_space_size via GAME_CONFIGS dict
  - Added --download flag to pull data from HuggingFace before training
  - Added per-game save directories (dynamics_checkpoints/pong/,
  dynamics_checkpoints/asterix/)
  - Added wandb tags for game name and model type for filtering runs
  - Overhauled wandb rollout logging:
    - rollout/best_final_step_mse_per_epoch — scalar tracking running
  minimum of step-50 rollout MSE, x-axis mapped to epoch
    - rollout/best_curve — graph titled "MSE over Best Rollout"
  (rollout_step vs mse), logged once at end of training
    - rollout/best_curve_table — table with [rollout_step, mse,
  best_epoch] columns
    - rollout/all_curves_table — accumulated table with [epoch,
  rollout_step, mse] for all eval epochs, logged once at end
    - Removed: 50 individual rollout/step_*_mse charts,
  rollout/all_curves line_series graph, rollout/best_epoch scalar

  4. offline.sh Updates
  - Now takes positional args: sbatch offline.sh <game> <model_type>
  - Restored per-model-type hyperparameters (baseline gets num_blocks=2,
  STU gets num_blocks=1 + STU params, etc.)
  - Uses --game flag instead of manual --data_dir/--checkpoint

  Key file locations

  - offline_training/train_dynamics_offline.py — main training script
  - offline_training/offline.sh — SLURM launch script (old version in
  offline_old.sh)
  - collect_asterix.sh — SLURM script for Asterix data collection (at
  project root)
  - dynamics_dataset_readme.md — HF dataset README (at project root)
  - GAME_CONFIGS in train_dynamics_offline.py — where to add new games

  - Multi-seed runs with wandb grouping for mean+std shading on scalar
